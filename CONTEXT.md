# Portfolio Knowledge

This context supplies facts for the portfolio chatbot. Sources point visitors to the portfolio material behind an answer.

## Language

**Knowledge source**:
An authored item in the portfolio knowledge corpus. A source has a title and a visitor-facing link.

**Knowledge index**:
The searchable copy of the knowledge sources used by the chatbot. The index can contain multiple passages from one source.

**Passage**:
A section of a knowledge source that retrieval can return as evidence for an answer.
