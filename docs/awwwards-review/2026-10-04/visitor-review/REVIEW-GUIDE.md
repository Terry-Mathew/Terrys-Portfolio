# Step 10B — Visitor review guide

## Result

Two standalone HTML pages are ready for a local concept review.
The pages need no local server or API key.
The pages use the same question, answer, source, and limits.
The static page keeps the answer visible.
The interactive page uses a native disclosure control.
Both pages use the local prototype content.
Their story link opens an offline excerpt from the current project source.
The pages compare the explanation control, not the full website layout.

## Reviewers

Use five people who resemble the website audience.
Include hiring managers and potential clients where possible.
Use reviewer codes R1 to R5. Do not collect personal contact details.
An owner review can find problems. It does not replace this visitor review.

## Steps

1. Open `static.html` for R1, R3, and R5.
2. Open `interactive.html` for R2 and R4.
3. Give each reviewer 30 seconds to inspect the first page.
4. Ask the reviewer to explain the portfolio assistant's search process.
5. Ask the reviewer to find the implementation story link.
6. Ask the reviewer whether this example performs live retrieval.
7. Record each answer without coaching the reviewer.
8. Open the other version.
9. Repeat the same tasks.
10. Ask which version makes the explanation easier to understand.
11. Record any confusion or blocked action.
12. Enter the results in `RESULTS.md`.

## Decision

Keep the static explanation unless the interaction provides a clear useful benefit.
Five reviews supply practical feedback. They do not establish statistical significance.
The second view can benefit from learning. Record presentation order.
A keyboard problem blocks integration until repaired.
Do not describe a preference as measured conversion improvement.

## Separate website review

Ask a reviewer to inspect the full local homepage.
Check whether the reviewer can identify one project and Terry's contribution within 30 seconds.
Ask the reviewer to find a contact action.
Record the browser and device used.
These tasks are separate from the concept comparison.
