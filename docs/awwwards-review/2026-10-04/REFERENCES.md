# Design reference review — 2026-10-04

## Result

Keep Terry’s editorial identity. Make project evidence easier to inspect.
Use interaction to explain one working system.
Keep the same explanation available as static content.

The audience includes hiring managers and potential clients.
The shared promise is “From complexity to clarity.”
The promise describes the story structure. The promise does not assert a measured business result.

The concept will not require 3D, audio, or game navigation.

## Design rules

| Element | Rule |
| --- | --- |
| Headings | Keep Oswald. Use large type for section hierarchy. |
| Editorial text | Keep Newsreader. Use short, readable project introductions. |
| Body text | Keep the existing body type. Allow content to determine section height. |
| Color | Keep warm paper, graphite, and the orange accent. |
| Spacing | Give evidence, explanation, and actions separate space. |
| Personal images | Keep Terry’s real photos. |
| Project images | Use real product screens or clearly labeled illustrations. |
| Motion | Explain order, relationships, and state changes. |
| Static alternative | Show the same project explanation without motion or interaction. |
| Contact | Provide separate role and project discussion actions. |
