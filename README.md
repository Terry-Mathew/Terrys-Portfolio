# Terry Mathew — Portfolio

Personal editorial portfolio: product, data, AI and systems work, independent experiments and life off the clock.

## Stack

- TanStack Start (SSR) + React 19 + TypeScript
- Vite + Tailwind CSS v4
- Deploy target: Cloudflare Workers (see `wrangler.jsonc`)

## Development

You need Node.js 20+ and npm.

```sh
npm i
npm run dev
```

## Placeholders

Favicon/OG/manifest, the RAG chat widget (`src/components/site/ChatWidget.tsx`), knowledge stubs
(`src/content/knowledge/`) and `wrangler.jsonc` are placeholders. Real assets and the RAG backend
wiring (Workers AI + Vectorize) land next — see `docs/STRUCTURAL-IMPROVEMENTS.md`.
