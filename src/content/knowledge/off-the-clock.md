# Off The Clock

Outside work, Terry rides a Royal Enfield, prefers long roads over short trips, and
stops to feed birds that clearly did not read the manual about personal space.

He travels to find different places and the same questions. He is interested in
how people behave when no system is telling them what to do, which is a large part
of why he builds data and AI products for work.

The site photography comes from those trips: motorcycle sunsets on highways, birds
in a garden, basalt forts in Mahad, and streets worth stopping on.

## What he likes outside work

Asked directly, this is the short answer. Five things, all of them real:

- Motorcycles — a Royal Enfield, and long roads chosen for their length rather
  than their destination.
- Travelling to see places he has not seen, and returning with the same
  questions he left with.
- Photography on those trips — motorcycle sunsets, birds, stone.
- Birds. He stops for them. They do not always stop for him.
- Long roads over short trips, which is the same preference stated twice.

## Editing this file

Write in normal prose. The chatbot reads the sentences as written, so full
sentences answer questions far better than bullet fragments. The first `# heading`
becomes the source title shown in the chat.

Ask a question this file should answer, then check that the answer is actually
in the text. A section written for the reader is not always a section retrieval
can find — "what does he like outside work" is a different set of words than
"outside work, Terry rides", and only one of them is in the file.

Add a new file for a new topic — anything `.md` in this folder is picked up
automatically. Prefix a file with `_` to keep it out of the index while you draft it.
